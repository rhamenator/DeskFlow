# DeskFlow

A generic client/product/task diary based on the durable JH concepts. It keeps
the initial boundary small: active clients, product review dates, and a
deterministic due-work queue. Legacy mutual-fund/client data, office identity,
Word output, and email files are not copied.

```powershell
cargo test
cargo run
```

Next slices: contacts/groups, notes/history, configurable products, document
links, recurring diary items, import validation, templates, and pluggable
email/calendar integrations. It is a workflow tool, not a source of investment
advice or market valuations.
